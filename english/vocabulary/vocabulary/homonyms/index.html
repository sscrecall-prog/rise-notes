🔰 Homonym Kya Hai? (What is a Homonym?)

Paribhasha (Definition) Homonym wo shabd hain jo same spelling ya same sound rakhte hain lekin unke alag-alag meanings hote hain.
(Homonyms are words that have the same spelling or sound but different meanings.)

🔊 Homophones

Same sound, alag spelling + meaning (same sound, different spelling and meaning)

e.g. Access / Excess • Aisle / Isle • Cite / Site / Sight • Pray / Prey

🔍 Homographs

Same spelling, alag meaning (kabhi kabhi alag pronunciation) (same spelling, different meaning or pronunciation)

e.g. Refuse (kachra) / Refuse (inkaar) • Desert (tyaag) / Desert (registan)
